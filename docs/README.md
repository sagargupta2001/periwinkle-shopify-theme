# Periwinkle theme docs

| Doc | Read it when… |
|---|---|
| [project-overview.md](project-overview.md) | You're new to the repo: what the store is, how the GitHub ↔ Shopify sync works, the directory map, and what's on each page. |
| [customizations.md](customizations.md) | You're touching the header, menus, slideshow, or any `periwinkle-*` section. It lists every change from Dawn, with the gotchas. |
| [design-guide.md](design-guide.md) | You're building or restyling anything: colour palette, schemes, typography, spacing, shape, imagery and motion. |
| [conventions.md](conventions.md) | You're writing code: section, CSS and JS conventions, accessibility, and how to verify a change. |
| [our-story-page.md](our-story-page.md) | You're working on the Our Story page: content model, layout, and the growing-periwinkle animation. |
| [store-status.md](store-status.md) | You need to know what's still open before or after launch, or how collections, menus, shipping and payments are set up right now. |
| [decisions.md](decisions.md) | You're about to change collections, menus, tags, shipping or product listings, and want to know why they're the way they are. |

Keep these docs current. When a PR adds a section or changes a pattern, update
the matching doc in the same PR. When you change store data in the Shopify
admin (collections, menus, tags, shipping, discounts), update
`store-status.md`, and add an entry to `decisions.md` if the change is
structural.
